# Karina Code Canvas

Build a modern, responsive personal developer portfolio website for a Computer Science student named Karina.

DESIGN REFERENCE:
Use https://aahanabobade-portfolio.vercel.app/ as a visual reference for the overall portfolio experience.

I also want a VS Code-inspired interface:
- Explorer sidebar with clickable navigation.
- Editor-style tabs for different sections.
- A clean, professional developer aesthetic.
- Light blue, white and subtle neutral colors.
- Responsive layout for desktop, tablet and mobile.

SECTIONS:

1. HOME
- Introduction: Hi, I'm Karina.
- Computer Science Student / Backend Developer.
- Short professional introduction.
- Buttons for Projects, Contact and Resume.
- Profile image placeholder.

2. ABOUT
- Computer Science background.
- Interest in backend development, software engineering, databases and cloud technologies.
- Hobbies: Reading, Art and Football.

3. PROJECTS
Include these projects with descriptions and technology tags:
- SecureLink URL Shortener — Node.js, Express, PostgreSQL, Docker.
- Mental Health Support App — Java, Swing, JDBC, MySQL.
- Container Health Monitor — Node.js, Express, Dockerode, React.

Each project should have GitHub and Live Demo links as editable placeholders.

4. SKILLS
- Languages: Java, Python, C, C++, JavaScript, SQL.
- Backend: Node.js, Express, FastAPI, REST APIs.
- Frontend: React, HTML, CSS.
- Databases: PostgreSQL, MySQL.
- Tools: Git, GitHub, Docker, Postman.

5. EXPERIENCE
Include my service-learning experience at Mahatma Phule Apang Prashikshan Kendra, where I completed 120 hours teaching spoken English, SQL/MySQL and Excel to young adults and also experiance teaching young girls English language as art of Lila Poonawalla Foundation

6. CONTACT
Include email, GitHub and LinkedIn links.

TECHNICAL REQUIREMENTS:
- Use React, TypeScript and Tailwind CSS.
- Use reusable components and clean project structure.
- Ensure all navigation works.
- Add subtle hover effects and smooth scrolling.
- Make the site responsive.
- Keep the design professional, minimal and readable.
- No purple gradients, excessive animations, glowing effects or unnecessary emojis.
- Do not invent personal details or achievements.
- Keep all personal links and content easy to edit.

Build the complete website, not just a landing page.
